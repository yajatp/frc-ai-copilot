# Scaffolding a new AdvantageKit subsystem

This is the spec-driven "just build it" mode: given a mechanism (e.g. "add an elevator",
"build a climber"), emit a profile-consistent skeleton in one pass instead of improvising
structure per-file. It assumes `skills/frc-reference/SKILL.md` conventions.

## Before you write anything

1. Call `profile_show` on the target team's profile to get real CAN IDs already in use and the
   team's current-limit norms — **never invent a CAN ID or current limit from nothing.** Pick the
   next free ID and flag it for human confirmation; match current limits to sibling mechanisms in
   the profile rather than guessing.
2. Confirm the vendor: 6369/Echo is pure CTRE Phoenix 6 → use the `XxxIOTalonFX` template. 6773/
   AlphaBot mixes CTRE + REVLib → ask (or infer from the profile's `vendors:` list / which
   mechanism this is) whether this specific mechanism should be `XxxIOTalonFX` or
   `XxxIOSparkMax`. The `XxxIO` interface and the `Xxx` subsystem are **vendor-agnostic either
   way** — only the `*IOTalonFX`/`*IOSparkMax` impl changes.
3. Decide the mechanism shape: this skill templates the common case, a **single-motor,
   position-controlled rotary mechanism** (pivot/arm/wrist — mirrors Echo's `Intake`/`Climber`).
   For a flywheel/velocity-controlled mechanism, drop the position control loop and gains for a
   velocity one (mirrors `Shooter`/`IntakeFlywheel`); for a multi-motor mechanism, add a
   `motorIdFollower` to the hardware record and a `.setControl(new Follower(leaderId, invert))`
   call — the file *set* doesn't change either way.

## File set (subsystem `Foo`, package `frc.robot.subsystems.foo`)

For a mechanism named `Foo` (adjust casing: `Foo`/`foo`/`FOO` per Java convention), create:

1. `FooConstants.java` — hardware/gains/motor-config records.
2. `FooIO.java` — the vendor-agnostic interface + `@AutoLog`-annotated inputs.
3. `FooIOTalonFX.java` (or `FooIOSparkMax.java`) — the real hardware impl.
4. `FooIOSim.java` — physics-sim impl (recommended; don't skip it the way Echo skipped it for
   most non-drive mechanisms — see the gotcha in `frc-reference`).
5. `Foo.java` — the subsystem.
6. **Wiring**: edit `RobotContainer.java` — instantiate `Foo` under all three mode branches
   (`REAL`/`SIM`/default-`REPLAY`), each with the IO appropriate to that mode, and bind any
   commands/triggers.

**Do not create `FooIOInputsAutoLogged.java` by hand.** It's generated by the `akit-autolog`
annotation processor from `@AutoLog` on `FooIOInputs` at compile time.

### 1. `FooConstants.java`

package frc.robot.subsystems.foo;

import com.ctre.phoenix6.signals.NeutralModeValue;
import edu.wpi.first.math.system.plant.DCMotor;

public class FooConstants {
  public static final double kPositionToleranceRadians = 0.05;
  // Rotor rotations -> mechanism rotations. Set from the real gearbox ratio.
  public static final double kGearingRatioSensorToMechanism = 1.0; // TODO

  public static final GravityTypeValue gravityType = GravityTypeValue.Arm_Cosine; // or Elevator_Static

  public record FooHardware(int motorId) {} // add motorIdFollower for multi-motor

      double p, double i, double d, double v, double s, double g, double a,

      DCMotor motorType, double momentOfInertiaKgM2, boolean simulateGravity) {}

### 2. `FooIO.java`

```java
package frc.robot.subsystems.foo;

import org.littletonrobotics.junction.AutoLog;

public interface FooIO {

  @AutoLog
  class FooIOInputs {
    public boolean isMotorConnected = false;
    public double positionRadians = 0.0;
    public double velocityRadPerSec = 0.0;
    public double appliedVolts = 0.0;
    public double statorCurrentAmps = 0.0;
    public double supplyCurrentAmps = 0.0;
    public double temperatureCelsius = 0.0;
  }

  // Every method defaults to a no-op, so `new FooIO() {}` is a legal, zero-effort
  // Noop implementation for REPLAY (mirrors Echo's ModuleIO/GyroIO idiom — no
  // separate FooIONoop.java needed).
  default void updateInputs(FooIOInputs inputs) {}

  default void setPosition(double positionRadians) {}

  default void stop() {}

  default void setGains(double p, double i, double d, double v, double s, double g, double a) {}

  default void setBrakeMode(boolean brake) {}

  default double getPosition() {
    return 0.0;
  }
}
```

### 3a. `FooIOTalonFX.java` (CTRE — 6369/Echo default)

```java
package frc.robot.subsystems.foo;

import com.ctre.phoenix6.BaseStatusSignal;
import com.ctre.phoenix6.StatusSignal;
import com.ctre.phoenix6.configs.Slot0Configs;
import com.ctre.phoenix6.configs.TalonFXConfiguration;
import com.ctre.phoenix6.controls.MotionMagicExpoVoltage;
import com.ctre.phoenix6.hardware.TalonFX;
import com.ctre.phoenix6.signals.FeedbackSensorSourceValue;
import com.ctre.phoenix6.signals.InvertedValue;
import com.ctre.phoenix6.signals.NeutralModeValue;
import edu.wpi.first.math.util.Units;
import edu.wpi.first.units.measure.*;
import frc.robot.subsystems.foo.FooConstants.FooGains;
import frc.robot.subsystems.foo.FooConstants.FooHardware;
import frc.robot.subsystems.foo.FooConstants.FooMotorConfiguration;

public class FooIOTalonFX implements FooIO {

  private final TalonFX motor;
  private final TalonFXConfiguration config = new TalonFXConfiguration();
  private final MotionMagicExpoVoltage positionControl = new MotionMagicExpoVoltage(0.0);

  private StatusSignal<Angle> position;
  private StatusSignal<AngularVelocity> velocity;
  private StatusSignal<Voltage> appliedVolts;
  private StatusSignal<Current> supplyCurrentAmps;
  private StatusSignal<Current> statorCurrentAmps;
  private StatusSignal<Temperature> temperatureCelsius;

  public FooIOTalonFX(FooHardware hardware, FooMotorConfiguration cfg, FooGains gains) {
    motor = new TalonFX(hardware.motorId());

    config.Slot0.kP = gains.p();
    config.Slot0.kI = gains.i();
    config.Slot0.kD = gains.d();
    config.Slot0.kS = gains.s();
    config.Slot0.kV = gains.v();
    config.Slot0.kA = gains.a();
    config.Slot0.kG = gains.g();
    config.Slot0.GravityType = FooConstants.gravityType;

    config.Feedback.FeedbackSensorSource = FeedbackSensorSourceValue.RotorSensor;
    config.Feedback.SensorToMechanismRatio = FooConstants.kGearingRatioSensorToMechanism;

    config.MotionMagic.MotionMagicCruiseVelocity =
        Units.radiansToRotations(gains.maxVelocityRadPerSec());
    config.MotionMagic.MotionMagicAcceleration =
        Units.radiansToRotations(gains.maxAccelerationRadPerSecSquared());
    config.MotionMagic.MotionMagicJerk = Units.radiansToRotations(gains.jerkRadPerSecCubed());

    config.CurrentLimits.SupplyCurrentLimit = cfg.supplyCurrentLimitAmps();
    config.CurrentLimits.SupplyCurrentLimitEnable = cfg.enableSupplyCurrentLimit();
    config.CurrentLimits.StatorCurrentLimit = cfg.statorCurrentLimitAmps();
    config.CurrentLimits.StatorCurrentLimitEnable = cfg.enableStatorCurrentLimit();

    config.MotorOutput.NeutralMode = cfg.neutralMode();
    config.MotorOutput.Inverted =
        cfg.invert() ? InvertedValue.CounterClockwise_Positive : InvertedValue.Clockwise_Positive;

    motor.setPosition(0.0);
    motor.getConfigurator().apply(config, 1.0);

    position = motor.getPosition();
    velocity = motor.getVelocity();
    appliedVolts = motor.getMotorVoltage();
    supplyCurrentAmps = motor.getSupplyCurrent();
    statorCurrentAmps = motor.getStatorCurrent();
    temperatureCelsius = motor.getDeviceTemp();

    BaseStatusSignal.setUpdateFrequencyForAll(
        FooConstants.kStatusSignalUpdateFrequencyHz,
        position, velocity, appliedVolts, supplyCurrentAmps, statorCurrentAmps, temperatureCelsius);
    motor.optimizeBusUtilization(0.0, 1.0);
  }

  @Override
  public void updateInputs(FooIOInputs inputs) {
    inputs.isMotorConnected =
        BaseStatusSignal.refreshAll(
                position, velocity, appliedVolts, supplyCurrentAmps, statorCurrentAmps, temperatureCelsius)
            .isOK();
    inputs.positionRadians = Units.rotationsToRadians(position.getValueAsDouble());
    inputs.velocityRadPerSec = Units.rotationsToRadians(velocity.getValueAsDouble());
    inputs.appliedVolts = appliedVolts.getValueAsDouble();
    inputs.statorCurrentAmps = statorCurrentAmps.getValueAsDouble();
    inputs.supplyCurrentAmps = supplyCurrentAmps.getValueAsDouble();
    inputs.temperatureCelsius = temperatureCelsius.getValueAsDouble();
  }

  @Override
  public void setPosition(double positionRadians) {
    motor.setControl(positionControl.withPosition(Units.radiansToRotations(positionRadians)));
  }

  @Override
  public void stop() {
    motor.stopMotor();
  }

  @Override
  public void setGains(double p, double i, double d, double v, double s, double g, double a) {
    var slot0 = new Slot0Configs();
    slot0.kP = p; slot0.kI = i; slot0.kD = d; slot0.kS = s; slot0.kV = v; slot0.kA = a; slot0.kG = g;
    motor.getConfigurator().apply(slot0);
  }

  @Override
  public void setBrakeMode(boolean brake) {
    motor.setNeutralMode(brake ? NeutralModeValue.Brake : NeutralModeValue.Coast);
  }

  @Override
  public double getPosition() {
    return position.getValueAsDouble();
  }
}
```

### 3b. `FooIOSparkMax.java` (REV — 6773/AlphaBot mechanisms)

Same interface, REVLib's unified `Spark`/config API instead of Phoenix 6. Current limit goes
through `smartCurrentLimit`, not a stator/supply pair — map both `FooMotorConfiguration` fields
onto it (or add a REV-specific config record if the team wants finer control). **Check the
REVLib vendordep version in the target repo** — this API surface (`SparkMax` + `SparkMaxConfig` +
`SparkClosedLoopController`, `.configure(...)`) is current for 2025+ REVLib; older/newer versions
may differ.

```java
package frc.robot.subsystems.foo;

import com.revrobotics.spark.SparkMax;
import com.revrobotics.spark.SparkBase.PersistMode;
import com.revrobotics.spark.SparkBase.ResetMode;
import com.revrobotics.spark.SparkClosedLoopController;
import com.revrobotics.spark.SparkLowLevel.MotorType;
import com.revrobotics.spark.config.ClosedLoopConfig.FeedbackSensor;
import com.revrobotics.spark.config.SparkMaxConfig;
import edu.wpi.first.math.util.Units;
import frc.robot.subsystems.foo.FooConstants.FooGains;
import frc.robot.subsystems.foo.FooConstants.FooHardware;
import frc.robot.subsystems.foo.FooConstants.FooMotorConfiguration;

public class FooIOSparkMax implements FooIO {

  private final SparkMax motor;
  private final SparkClosedLoopController controller;

  public FooIOSparkMax(FooHardware hardware, FooMotorConfiguration cfg, FooGains gains) {
    motor = new SparkMax(hardware.motorId(), MotorType.kBrushless);
    controller = motor.getClosedLoopController();

    SparkMaxConfig config = new SparkMaxConfig();
    config
        .inverted(cfg.invert())
        .idleMode(cfg.neutralMode() == com.ctre.phoenix6.signals.NeutralModeValue.Brake
            ? com.revrobotics.spark.config.SparkBaseConfig.IdleMode.kBrake
            : com.revrobotics.spark.config.SparkBaseConfig.IdleMode.kCoast)
        .smartCurrentLimit((int) cfg.statorCurrentLimitAmps());
    config.closedLoop
        .feedbackSensor(FeedbackSensor.kPrimaryEncoder)
        .pid(gains.p(), gains.i(), gains.d());

    motor.configure(config, ResetMode.kResetSafeParameters, PersistMode.kPersistParameters);
  }

  @Override
  public void updateInputs(FooIOInputs inputs) {
    inputs.isMotorConnected = true; // REV doesn't expose a single "connected" signal the same
                                     // way Phoenix StatusSignals do; wire up a fault/sticky-fault
                                     // check here if the team needs one.
    inputs.positionRadians = Units.rotationsToRadians(motor.getEncoder().getPosition());
    inputs.velocityRadPerSec =
        Units.rotationsPerMinuteToRadiansPerSecond(motor.getEncoder().getVelocity());
    inputs.appliedVolts = motor.getAppliedOutput() * motor.getBusVoltage();
    inputs.statorCurrentAmps = motor.getOutputCurrent();
    inputs.temperatureCelsius = motor.getMotorTemperature();
  }

  @Override
  public void setPosition(double positionRadians) {
    controller.setReference(Units.radiansToRotations(positionRadians),
        com.revrobotics.spark.SparkBase.ControlType.kPosition);
  }

  @Override
  public void stop() {
    motor.stopMotor();
  }

  @Override
  public double getPosition() {
    return Units.radiansToRotations(motor.getEncoder().getPosition());
  }
}
```

### 4. `FooIOSim.java`

Mirrors `ModuleIOSim`'s pattern: run the closed loop in software against a `DCMotorSim` (or
`SingleJointedArmSim` if gravity/travel-limits matter), no CAN at all.

```java
package frc.robot.subsystems.foo;

import edu.wpi.first.math.controller.PIDController;
import edu.wpi.first.math.system.plant.LinearSystemId;
import edu.wpi.first.wpilibj.simulation.DCMotorSim;
import frc.robot.subsystems.foo.FooConstants.SimulationConfiguration;

public class FooIOSim implements FooIO {

  private final DCMotorSim sim;
  private final PIDController controller;
  private double appliedVolts = 0.0;
  private boolean closedLoop = false;

  public FooIOSim(SimulationConfiguration cfg, FooConstants.FooGains gains) {
    sim = new DCMotorSim(
        LinearSystemId.createDCMotorSystem(cfg.motorType(), cfg.momentOfInertiaKgM2(), 1.0),
        cfg.motorType());
    controller = new PIDController(gains.p(), gains.i(), gains.d());
  }

  @Override
  public void updateInputs(FooIOInputs inputs) {
    if (closedLoop) {
      appliedVolts = controller.calculate(sim.getAngularPositionRad());
    }
    sim.setInputVoltage(edu.wpi.first.math.MathUtil.clamp(appliedVolts, -12.0, 12.0));
    sim.update(0.02);

    inputs.isMotorConnected = true;
    inputs.positionRadians = sim.getAngularPositionRad();
    inputs.velocityRadPerSec = sim.getAngularVelocityRadPerSec();
    inputs.appliedVolts = appliedVolts;
    inputs.statorCurrentAmps = Math.abs(sim.getCurrentDrawAmps());
  }

  @Override
  public void setPosition(double positionRadians) {
    closedLoop = true;
    controller.setSetpoint(positionRadians);
  }

  @Override
  public void stop() {
    closedLoop = false;
    appliedVolts = 0.0;
  }

  @Override
  public double getPosition() {
    return sim.getAngularPositionRad();
  }
}
```

### 5. `Foo.java`

```java
package frc.robot.subsystems.foo;

import edu.wpi.first.wpilibj2.command.SubsystemBase;
import org.littletonrobotics.junction.AutoLogOutput;
import org.littletonrobotics.junction.Logger;

public class Foo extends SubsystemBase {
  public enum FooGoal {
    kStow(0.0),
    kDeploy(1.0); // TODO real setpoints, radians

    private final double goalRadians;
    FooGoal(double goalRadians) { this.goalRadians = goalRadians; }
    public double getGoalRadians() { return goalRadians; }
  }

  private final FooIO io;
  private final FooIOInputsAutoLogged inputs = new FooIOInputsAutoLogged();
  private FooGoal goal = FooGoal.kStow;

  public Foo(FooIO io) {
    this.io = io;
  }

  @Override
  public void periodic() {
    io.updateInputs(inputs);
    Logger.processInputs("Foo/Inputs", inputs);
    Logger.recordOutput("Foo/Goal", goal);

    if (goal != null) {
      io.setPosition(goal.getGoalRadians());
    }
  }

  public void setGoal(FooGoal goal) {
    this.goal = goal;
  }

  public void stop() {
    goal = null;
    io.stop();
  }

  @AutoLogOutput(key = "Foo/AtGoal")
  public boolean atGoal() {
    return goal != null
        && Math.abs(goal.getGoalRadians() - io.getPosition()) < FooConstants.kPositionToleranceRadians;
  }
}
```

### 6. Wiring into `RobotContainer.java`

Add the field, then instantiate it in **all three** mode branches of the constructor's
`switch (Constants.currentMode)` — this is the step most likely to be half-done (see the
Shooter/Hood/Intake/Transfer/Index gotcha in `frc-reference`); don't repeat it here.

```java
public final Foo foo;
// ...
switch (Constants.currentMode) {
  case REAL:
    foo = new Foo(new FooIOTalonFX(FooConstants.kFooHardware, FooConstants.kMotorConfiguration, FooConstants.kFooGains));
    break;
  case SIM:
    foo = new Foo(new FooIOSim(FooConstants.kSimulationConfiguration, FooConstants.kFooGains));
    break;
  default: // REPLAY
    foo = new Foo(new FooIO() {}); // legal no-op — see FooIO's default methods
    break;
}
```

## Before calling it done

Run the `frc-reference` skill's plan-review checklist over the generated files and the
`RobotContainer` edit: CAN ID checked against the profile, units (rotations↔radians, gearing)
verified, all three mode branches present and mode-correct, explicit current limits set and
sane, and the subsystem actually wired to a command/trigger somewhere (not just instantiated and
ignored).
